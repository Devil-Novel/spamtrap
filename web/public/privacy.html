Privacy Policy

Last updated: October 29, 2026

Information We Collect

To keep Spam Trap running properly, we store the information needed to protect your server. This includes your server configuration such as channel IDs, selected moderation action, enabled experiments, moderation logs, catch statistics, and Discord OAuth session data for the web dashboard.

If your administrators enable any of the optional server protections (scam links, raid, mass mentions, repeated messages, new-member restrictions, webhook spam, anti-nuke), we also store that configuration: which features are on, the chosen actions and thresholds, trusted role IDs, trusted webhook IDs, and your blocked/allowed domain lists. Each protection incident is recorded as the feature that fired, the account or webhook ID involved, the channel ID, a short reason label, a timestamp, and the action outcome. Incident records never contain message text.

If the Forward Message experiment is enabled, the content of detected spam messages may also be stored in moderation logs.

Information We Don't Collect

Spam Trap respects your privacy. By default, Spam Trap does not process messages outside your trap channels. We never collect passwords, email addresses, payment information, or any sensitive personal data. We do not track users across different servers or sell your information to third parties.

Optional Server-Wide Message Processing

Every server protection is off by default. When a server administrator turns one on, Spam Trap processes messages in that server's ordinary channels in memory only to check for the enabled condition (for example links on the server's block list, or many mentions in a short time). Message text is not stored: repeated-message detection keeps only short-lived hashes, and the other checks keep only temporary counters and timestamps, all of which expire within the configured detection window (at most a few minutes). Scam-link checks run locally inside the bot and never send message content to any external service; the bot does not scan attachments or follow links. Administrators can switch each protection off at any time with /protection.

How We Use Your Data

Your data is only used to operate Spam Trap. This includes protecting your server, saving your configuration, displaying dashboard statistics, recording moderation actions, and providing the features you enable.

Data Storage and Security

Your data is stored securely on our Railway-hosted infrastructure. Dashboard cookies contain only a signed, random session ID. Discord access tokens and profile details stay in server memory. Sessions expire after at most seven days or when the Discord access token expires, whichever comes first. Signing out invalidates the session on the server; a bot restart signs dashboard users out.

Data Retention

One rolling database backup is retained for recovery from a damaged write. It is replaced on the next write. Removing the bot deletes the server from both the active database and its rolling backup. Failed softban unbans are kept as pending recovery records (user ID, server ID, a unique ban reason, attempt count and retry time) until resolved or the bot is removed.

Your server configuration is stored only while Spam Trap remains in your server; removing the bot deletes it automatically (see Data Deletion below). Recent moderation activity is limited to the latest five actions shown per server. We do not keep a separate log of every individual moderation action beyond that; only aggregate catch counts (per-server and site-wide totals) are retained.

For the server protections: temporary counters and hashes live only in memory and expire within the detection window (and are cleared whenever the bot restarts). Protection incident records are limited to the latest 20 per server plus a running count, and are deleted with the rest of the server's data when the bot is removed.

Alerts and log entries the bot posts in your own Discord channels are ordinary Discord messages. They remain in Discord until someone deletes them there; we do not control or retain them.

Data Deletion

Removing Spam Trap from your server automatically and permanently deletes that server's stored configuration and statistics; no need to contact us separately. If you'd rather keep your configuration for later, use the /spamtrap disable command instead, which turns off trap-channel moderation without deleting settings. Optional server protections have separate switches under /protection. For any other data question, reach out through the contact options below.

Children's Privacy

Spam Trap is not intended for users under the age of 13 and follows Discord's minimum age requirements.

Website Analytics

The spamtrap.help website (not the bot itself) uses Google Analytics to understand how many people visit the site and which pages they view. Google Analytics uses cookies and collects information such as your approximate location, device and browser type, and pages visited. This applies only to browsing spamtrap.help; it has no connection to your Discord account, server data, or anything the bot itself collects. You can opt out using the Google Analytics Opt-out Browser Add-on, or by using your browser's tracking-protection settings.

Third Party Services

Spam Trap uses the Discord API for bot functionality, Railway for hosting, and Google Analytics for website traffic statistics. Your use of these services is also subject to their respective privacy policies.

Policy Updates

This Privacy Policy may be updated from time to time. The latest revision date will always appear at the top of this page. Continuing to use Spam Trap means you accept any updates.

Contact

If you have any questions about this Privacy Policy, you can reach us through GitHub Issues or our Discord server.
