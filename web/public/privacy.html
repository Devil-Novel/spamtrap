SPAM TRAP

Privacy Policy

Last updated: July 7, 2026

Spam Trap ("the Bot", "we", "us") is a Discord moderation bot designed to catch spam bots and compromised accounts. This Privacy Policy explains what data we collect, how we use it, and your rights regarding that data.

1. Data We Collect

When you add Spam Trap to your Discord server, we collect and store the following data:

  • Server configuration: Server ID, trap channel ID(s), log channel ID, selected action (softban/ban/disabled), enabled experiments, and custom message templates.
  • Moderation logs: When a user triggers the trap, we log their User ID, username, the action taken, and the content of the message that triggered the trap (if the Forward Message experiment is enabled).
  • Catch statistics: A counter of total catches per server and globally.

When you log in to the web dashboard, we additionally collect:

  • Discord OAuth2 data: Your User ID, username, avatar, and the list of servers you manage. This data is stored in an encrypted session cookie and is not persisted on our servers.

2. Data We Do NOT Collect

  • We do not read or store messages from any channel other than the designated trap channel(s).
  • We do not collect message content unless the Forward Message experiment is explicitly enabled by a server administrator.
  • We do not collect or store passwords, email addresses, or payment information.
  • We do not track users across servers.
  • We do not sell, share, or distribute any collected data to third parties.

3. How We Use Your Data

All collected data is used exclusively for the following purposes:

  • Operating the spam trap moderation system (detecting and actioning spammers).
  • Storing your server's configuration so the bot works correctly after restarts.
  • Displaying moderation statistics to server administrators via commands and the web dashboard.
  • Logging moderation actions to your designated log channel.

4. Data Storage and Security

All data is stored in a JSON database on a secured Railway.app server. The database is only accessible by the bot process. Web dashboard sessions use encrypted cookies that expire after 7 days.

5. Data Retention

  • Server configuration: Retained as long as the bot is in your server. When the bot is removed from a server, the configuration is retained but can be deleted upon request.
  • Moderation logs: The last 5 actions per server are stored. Older actions are automatically removed. The global log is capped at 5,000 entries.
  • Dashboard sessions: Expire after 7 days and are not stored server-side.

6. Data Deletion

You can request deletion of all data associated with your server by:

  • Removing the bot from your server and contacting us.
  • Using the /spamtrap disable command to clear trap channels (configuration is retained but the bot stops collecting data).

7. Children's Privacy

Spam Trap does not knowingly collect data from children under 13. The bot operates within Discord, which requires users to be at least 13 years old per Discord's own Terms of Service.

8. Third-Party Services

Spam Trap uses the following third-party services:

  • Discord API: For bot functionality and OAuth2 authentication. Subject to Discord's Privacy Policy.
  • Railway.app: For hosting. Subject to Railway's Privacy Policy.

9. Changes to This Policy

We may update this Privacy Policy from time to time. Changes will be reflected by updating the "Last updated" date at the top of this page. Continued use of the bot after changes constitutes acceptance of the updated policy.

10. Contact

If you have questions about this Privacy Policy or want to request data deletion, you can:

  • Open an issue on our GitHub repository.
  • Contact us through Discord.
