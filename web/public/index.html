How It Works

1

A trap channel is created

Pick any text channel or create a new one. Name it something normal like "general" or "chat". Run /spamtrap channel #your-channel.

2

A message is detected

Spam bots blast every visible channel. When one hits your trap, the bot catches it instantly. Admins and server owners are always safe.

3

The user gets a DM

The bot sends a message explaining the account may be compromised, with steps to recover it: change password, enable 2FA, check authorized apps.

4

The action runs

Softban (default): ban then unban to purge messages while allowing the user to rejoin. Or permanent ban. Their spam is wiped from the server.

5

Everything is logged

An embed is posted in your mod log channel with user info, action taken, and a running catch counter. Your mod team sees everything.

Commands

/spamtrap channel #chSet the trap channel. Posts and pins a multilingual warning.
/spamtrap log #chSet the mod log channel for action reports.
/spamtrap action typeChoose softban, ban, or disabled.
/spamtrap toggleEnable or disable experiments via dropdown menu.
/spamtrap experimentsView all experiments with their current status.
/spamtrap statusView the full current configuration.
/spamtrap statsView catch statistics and recent actions.
/spamtrap channels #1 #2...Set up to 5 trap channels (needs Many Traps experiment).
/spamtrap-messagesCustomize warning, DM, and log messages via modal.
/spamtrap disableTurn off the trap. Keeps settings for later.
