How It Works

1

Bot joins and creates a trap

When invited, Spam Trap auto-creates a 🪤│spam-trap channel at the top of your server with a pinned warning and a Translations button inside.

2

A message is detected

Spam bots blast every visible channel. When one hits your trap, the bot catches it instantly. Admins and server owners are exempt from the trap. Any other member can trigger it, including someone posting by mistake.

3

The action runs

Softban (default): ban then unban to purge messages while allowing the user to rejoin. Or permanent ban. Their spam is wiped from the server.

4

The user gets a DM

The bot sends a message explaining the account may be compromised, with steps to recover it: change password, enable 2FA, check authorized apps.

5

Everything is logged

An embed is posted in your mod log channel with user info, action taken, and a running catch counter. Your mod team sees everything.

Beyond the trap: optional server protections

Seven extra protections for your ordinary channels. Every one is off by default, alert-only until you choose otherwise, and managed with /protection in Discord.

Scam links

Flags links to domains on your block list, plus suspected fake Nitro gifts and Discord look-alike domains. Checks run locally inside the bot: no external lookups, no attachment scanning, no redirect following. Heuristic matches can be wrong, so they're labelled as suspected.

Raid protection

Notices unusually large bursts of joins and starts a timed raid mode. Nobody is banned or timed out just for joining, and the server is never locked down. Needs the Server Members Intent, enabled by the bot operator.

Mass mentions

Counts user, role and @everyone/@here mentions per sender across all channels in a rolling window. Edited messages replace their earlier count instead of adding to it.

Repeated messages

Catches the same text posted again and again by one account, even across channels and with changed capitalization, spacing or invisible characters. Only short-lived hashes are kept, never the text.

New member restrictions

Optionally blocks links and attachments for a set number of minutes after someone joins. Trusted roles and staff are exempt.

Webhook spam

Detects floods of messages from a single webhook. Deletes the messages when configured, never the webhook itself. Trusted webhook IDs are skipped.

Anti-nuke

Watches the audit log for bursts of channel or role deletions, kicks, bans and dangerous role changes by one account. Alert-only by default, with optional containment that removes dangerous roles the bot is allowed to edit. It cannot restore what was deleted or act on accounts above its own role.

Alerts & incidents

Alerts go to your existing mod-log channel, never ping anyone, and are rate-limited so an attack can't flood the channel. The latest 20 incidents per server are kept, with the real outcome of each action, and no message content.

These protections are configured with slash commands only. /spamtrap disable turns off trap channels; each protection has its own switch under /protection.

Commands

/spamtrap channel #chSet the trap channel. Posts a multilingual warning.
/spamtrap log #chSet the mod log channel for action reports.
/spamtrap action typeChoose softban, ban, or disabled.
/spamtrap toggleEnable or disable experiments via dropdown menu.
/spamtrap experimentsView all experiments with their current status.
/spamtrap statusView the full current configuration.
/spamtrap statsView catch statistics and recent actions.
/spamtrap channels #1 #2...Set up to 5 trap channels (needs Many Traps).
/spamtrap-messagesCustomize warning, DM, and log messages via modal.
/spamtrap disableTurn off trap channels only. Keeps settings for later; server protections keep their own switches.
/protection statusProtection features, actions, limits, exemptions and any missing bot permissions. Administrator or owner only.
/protection recentThe latest 20 protection incidents and the total count. No message content is stored.
/protection feature name enabledSwitch scam, raid, mentions, repeats, newcomers, webhooks or antinuke on or off. All start off.
/protection limit name valueAdjust thresholds and windows (mention limit, repeat limit, join limit, timeout length, and more).
/protection action target typeMessages: alert, delete or timeout. Anti-nuke: alert or strip_roles. Alert is the default for both.
/protection trust role trustedExempt a role from the protections (up to 50; @everyone is refused).
/protection webhook id trustedTrust a webhook by its numeric ID so its messages are not checked. Never paste a webhook URL or token.
/protection domain list operation hostAdd or remove blocked and allowed domains. Subdomains match automatically; an explicit block always wins.
