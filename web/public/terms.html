  • The bot may automatically create a trap channel when joining a server (if it has the Manage Channels permission).
  • Soft-banned users are immediately unbanned and can rejoin the server.

5. Auto-Channel Creation

When Spam Trap joins a new server with the Manage Channels permission, it will automatically create a text channel named "spam-trap" at the top of the channel list. Server administrators can rename, move, or delete this channel and configure a different trap channel using the /spamtrap channel command.
